# 术语表（待定稿）

## 为什么需要这张表

LLM 是**逐条**翻译的。同一个 `Aramon` 出现在 70 条不同的句子里，如果每条独立送翻，
会得到「阿拉蒙 / 阿拉门 / 阿拉蒙族 / 阿蒙」好几种写法 —— 玩家会以为是不同阵营。
术语表的作用是给翻译脚本一份**强制替换表**：送翻前把专名替换成占位符（或放进 prompt 的
few-shot），回写后统一还原。这与 MajestyIIExtend / ArmyMenCHS 里「逐场景校对专名」是同一件事。

本表**目前是待定状态**：括号里的中文只是候选，不是官方译名。官中镜像只汉化了安装程序
（见 `docs/00-调研结论.md` §2），游戏本体没有可对照的官方中文，所以译名需要人工定一次，
之后全项目锁定。

## 通用规则（建议写进翻译脚本的 prompt）

1. **阵营名、神名、人名、地名一律用上表锁定译法**，不得按上下文意译。
2. `God` / `Monarch` 等泛称按语境译，不要与专名混用。
3. 界面短词（`OK`、`Cancel`、`Load Game`）走 01 组统一，不要在不同文件里译成不同写法。
4. 含 `%s` / `%d` 的句子，占位符必须保留且位置可调（中文语序），但数量与类型不可变。
5. 网页段落里的 `“ ”` 弯引号、`<FONT>` 标签照抄，不要转成直角引号或删标签。
6. 联机相关词（玩家名、房间名、聊天）**不译**：它们本来就不该进词条表，若发现这类条目
   出现在待译表里，置 `status = "skip"` 并记一笔。
