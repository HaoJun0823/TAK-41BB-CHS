## 第二轮收口（短句与全局一致性）

长文本定稿之后，又把 20 字以上的界面短句与任务提示过了一遍，专治「看着没错、读着别扭」
和同一专名多种写法：

| 动作 | 数量 | 落点 |
|---|---:|---|
| 长文本整段重写（剧情、百科、帮助、任务提示、报错文案） | 518 条 | `polish.json` + `apply_polish.py` |
| 专名 / 术语变体归一（伯里亚什→布里亚什、罗德斯石→罗德斯通、远征室→远征厅、战争室→作战室…） | 101 条变体规则 | `lore_terms.json` |
| 列表符号统一（`•` `●` `·` → `·`） | 211 条 | `normalize_punct.py` |
| 引号统一（`"…"` `'…'` `“…”` → `「…」`） | 73 条 | 同上 |
| 数字校验支持中文数字（一千、一百八十算命中） | 门禁增强 | `check_quality.py` |

修掉的两类系统性问题：

* **变体替换级联**：原先逐条 `str.replace`，`战争房间→作战室` 之后 `战室→作战室`
  又命中「作战室」里的子串，产出「作作战室」；改成一次性正则替换后不再发生。
* **定稿回退排版**：`polish.json` 存的是人手原文，套回时会把已归一的弯引号带回来；
  流水线因此固定为 B → A → C → 排版，标点归一必须最后跑。


残留的拉丁字母只剩三类，都是不该翻的：产品/技术名（DirectPlay、Boneyards、CD-ROM）、
错误码括注（`(INVALIDMODE)`）、服务器模板（`<$...$>` 内部）。
