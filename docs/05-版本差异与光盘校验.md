# 版本差异与光盘校验（4.0BB / 4.1BB）

## 一、为什么主菜单显示 `v4.0BB`

主菜单底部那行版本号**不是字典译文，是硬编码在 `KINGDOMS.icd` 里的**：

```
VA 0x212850   "Version\0v4.1BB\0"
VA 0x211FDC   "NOT_A_COMPATIBLE_VERSION\0\0\0\0 4.0BB\0"   ← 联机版本校验用的
```

所以它显示什么，完全取决于当前用的是哪份 `KINGDOMS.icd`。

## 二、两份主程序的区别

| | 4.0BB（当前主目录原先那份） | 4.1BB（`Total Annihilation Kingdoms_41BB/`） |
|---|---|---|
| PE 版本资源 | `30BB` | `41BB` |
| 内置版本串 | `v4.0BB` | `v4.1BB` |
| 文件日期 | 2010-11-24 | 2005-10-24 |
| md5 | `3db7cad2a6fb26173edff6ae5547bf75` | `f475c619c7d31371ab3964ccf578329f` |
| sha256 | `1144a394…` | `dfcb2673…`（文档基线） |
| 来源 | GOG 重打包（免 DRM） | 零售 4.0 补丁后的官方 4.1 更新 |
| 单位上限 | 150 | **500** |
| 光盘校验 | 已短路 | 要求光驱根目录有 `Kingdoms.ID` |

**其余文件（全部 HPI、`KINGDOMS.ID`、`Keys.TDF`、`Startup.tdf`）哈希完全一致。**

两份 `KINGDOMS.icd` 大小相同（2,277,500 字节），**只差 43 字节、24 段**。

## 四、光盘校验是怎么做的

`sub_48CFE0`（启动时）与 `sub_4A5120`（主菜单 PlayStory 分支）会问「盘在不在」：

```c
// sub_48CF20：只枚举光驱，不认硬盘
do {
    drive = sub_53AEB0(prev);        // GetDriveTypeA(drive) == 5 (DRIVE_CDROM)
    sprintf(name, "%c:\\%s", drive, file);   // 例如 "D:\Kingdoms.ID"
    f = fopen(name, "r");
} while (!f);
```

`sub_48CFE0` 先试工作目录的 `Kingdoms.ID` / `IronPlague.ID`，都没有才走上面的光驱搜索。
`sub_48CF20` 只看 **驱动器根目录**，所以把文件丢在硬盘任意目录没用 —— 必须是一个
`DRIVE_CDROM` 类型的盘符。

PlayStory 分支（`0x4A5120`）：

```asm
call sub_48D050            ; 要不要查盘
test al, al
je   正常流程               ; ← 4.1BB：不查盘就直接进
call sub_48CF00            ; 查 Kingdoms.ID
...
call sub_48CF10            ; 查 IronPlague.ID
test al, al
je   弹 INSERT_CD          ; ← 4.1BB：两个都没有就弹框
```

GOG 的 4.0BB 把这套直接短路了：`0x4A5146` 的 `je` 改成 `jmp`、`0x4A5159` 的偏移清零。

## 五、本项目的处理

只在**内存里**改这两处（`src/cd_patch.cpp`），磁盘文件一个字节不动：

| VA | 4.1BB 原字节 | 写入 |
|---|---|---|
| 0x4A5146 | `74 12` | `EB 12` |
| 0x4A5159 | `7D` | `00` |

在 `DllMain` 的 `DLL_PROCESS_ATTACH` 里同步执行（不能等初始化线程，主线程可能先跑到）。
写入前先 `memcmp` 校验原字节，不匹配就跳过 —— 同一份 DLL 在 4.0BB（GOG）上会报
「无需处理」，两者都能用。

### 踩过的坑

第一次把 4.0BB 的 **全部 6 处** `je→jmp` 都照抄，结果**主菜单花屏**（绿色噪点、右半屏全黑），
启动时间从 4 秒涨到 26 秒。说明 `0x4A7DDA` / `0x4BB817` 那两组分支**不只是光盘检查**，
无条件跳转把必要的初始化也跳过了。

最终只保留 PlayStory 的 2 处，画面完全正常：

```
cd: 光盘校验短路 2 处（无需处理 0，失败 0）
```

主菜单显示 `v4.1BB`，点「开始冒险」直接进战役选择，无任何提示框。

## 六、补充：启动变慢

4.1BB 冷启动约 19 秒，4.0BB 约 4 秒。属于该版本自身行为（启动流程里仍有其它
介质探测），与补丁无关，不影响游戏内表现。
